# CodeRabbit review exercise

This pull request is a **demo review exercise**. It adds a quarter filter to the wins dashboard and a Copy draft action to the performance-review builder.

Reviewers: please check asynchronous clipboard error handling, filtering semantics across calendar years, accessibility and keyboard behavior, and whether exported data matches the selected filters. The branch is not intended to be merged until findings are addressed.

No user data is sent to a server; existing browser-local storage behavior is unchanged.
